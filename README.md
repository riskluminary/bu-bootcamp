# bu-bootcamp
BU Online AI Programs Foundations Bootcamp

This repo contains work for the BU Master's in Computer Science CS Foundations Bootcamp.

## Structure

- Module 1
Development environment set up and first programs in Java.
- Module 2
Programming fundamentals (control flow, variables, Java methods, file operations)
- Module 3
Data structures (ArrayList, HashMap, HashSet, Stack) and object-oriented programming.
